# homebrew-tools

A Homebrew tap for tools by [Nithik R.](https://github.com/noinoiexists).

## Install

```sh
brew tap noinoiexists/tools
```



## fmevent

**A semantic `if` command line tool for macOS**

```sh
brew install fmevent
```


It turns a plain-English question about stdin into an exit status, so shells branch on meaning rather than on text. It runs Apple's on-device model. Nothing leaves your Mac, and the model only ever classifies. You decide what happens next.

**Requires macOS 27 (Golden Gate) with Apple Intelligence enabled**, plus the
on-device model weights, which macOS downloads separately and on its own schedule.

Full documentation, the routes and schema modes, and runnable examples live in the
[main repository](https://github.com/noinoiexists/fmevent).
